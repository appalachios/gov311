For an existing statute, open **Tennessee Code** from the [General Assembly’s legislation page](https://wapp.capitol.tn.gov/apps/BillInfo/Legislation). Use the section number from the document you are reading. The legislature links to LexisNexis for the Code. Its reader did not display the statute text to our automated reader. If that happens, open it in your browser. The [Library of Congress guide](https://guides.loc.gov/law-us-tennessee/legislative) also identifies Tennessee’s code and acts collections.

If you have a bill number, first [look up its history](../services/track-a-bill.md). Once a general bill becomes law, the Secretary of State assigns it a public chapter number. A public chapter shows the change lawmakers enacted, including when it takes effect. The Code organizes statutes by subject and incorporates those changes.
