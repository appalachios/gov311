Check the parcel’s city limits before using the State Fire Marshal’s list. Find the county and read the row for the incorporated municipality if the project is inside one. For a site outside city limits, read the county entry. The designation applies to the state residential building permit program. [State jurisdiction table and inspectors](https://www.tn.gov/commerce/fire/residential-permits/jurisdictions-inspectors.html) · [County parcel maps](find-a-property-map.md)

For example, Bedford County is listed as exempt, while Normandy has its own state residential building permit entry. A Normandy mailing address can also be outside the town. For a state-program address, check the state application and inspection instructions. For a locally enforced permit, contact the local building office with the parcel ID and project description. Ask separately about zoning, septic and trade permits as applicable. [State residential permit program](https://www.tn.gov/commerce/fire/residential-permits.html) · [Jurisdiction table](https://www.tn.gov/commerce/fire/residential-permits/jurisdictions-inspectors.html)
