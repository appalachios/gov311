Start with the county where the land sits. In the **Tennessee Property Viewer**, choose the county and search by street address, owner name or parcel ID. Select a result to see the parcel on the map and open its assessment details. Loudon and Polk counties are both available here. [Open the Tennessee Property Viewer](https://tnmap.tn.gov/assessment/) · [State search instructions](https://tnmap.tn.gov/assessment/whatsnew.html)

**Nine counties use local sites.** For Chester, Davidson, Hamilton, Hickman, Knox, Montgomery, Rutherford, Shelby or Williamson, open **FAQ** in the viewer and select **Are property maps for all Tennessee counties available on this site?** The answer links to each county’s site. For Knox County, go directly to **KGIS Maps**.
