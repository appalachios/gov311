Start with the parcel address in KGIS Maps. Confirm the property is in the City of Knoxville, then select **Maps → Planning and Zoning Maps → Zoning**. Write down the district code and any overlays. The city’s zoning page organizes the law by district, land use, site standards and application type. For example, a residential parcel can have both a base district and a hillside overlay, and both can affect the project. [City boundary lookup](https://www.knoxvilletn.gov/889/Development-Process) · [Zoning map instructions and ordinance](https://www.knoxvilletn.gov/893/Zoning)

For a proposed change, search the planning case number and read the map, staff report, comments and decision. Use the council records to check amendments, the final vote and when a change took effect. A planning case number will also help the recorder find the ordinance. [Planning case search](https://knoxplanning.org/cases/) · [Vance Road rezoning example](../services/follow-a-city-council-vote.md)
