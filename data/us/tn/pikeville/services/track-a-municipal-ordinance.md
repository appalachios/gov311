Pikeville’s charter sets the vote an ordinance needs. At least three board members must vote yes, and the recorder must enter each vote in the board journal. The mayor has one vote. The charter sets no general number of readings, and Municipal Code § 1-103 adopts Robert’s Rules where the charter and code leave a procedural question open. Tennessee’s general rule allows one reading if no applicable law or local rule calls for more. [Pikeville charter § 6](https://www.mtas.tennessee.edu/sites/default/files/private/charters/pikevill_cht.pdf#page=7) · [Code’s charter note](https://www.mtas.tennessee.edu/system/files/codes/Pikevill_frt.pdf) · [Municipal code, title 1](https://www.mtas.tennessee.edu/system/files/codes/pikevill_t-1.pdf) · [Tennessee ordinance procedure](https://www.mtas.tennessee.edu/reference/procedures-adopting-ordinances)

Pikeville’s posted agendas list budget amendment 12-8-O25 for a second reading on January 12, 2026, and a third on February 9. For a measure you are following, ask the recorder which rule governs its readings and get the journal entries and signed text. The city lists the recorder’s office at (423) 447-2919, extension 104. [Board agendas and minutes](https://pikevilletn.com/agendas-minutes/)

For a change to an existing ordinance, compare the proposed text with the current code section. Ask the recorder for any amendments passed since that edition. [Municipal code](https://www.mtas.tennessee.edu/code/municipal-code-pikeville)
