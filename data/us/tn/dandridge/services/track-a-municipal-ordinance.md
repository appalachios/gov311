Dandridge Municipal Code § 1-108 requires two readings on different days. The town adopted the revised code on September 10, 2019, by Ordinance 19/20-04. An older copy on the town website still calls for three readings. Use the revised § 1-108 to follow a proposal. [Current ordinance procedure](https://www.mtas.tennessee.edu/city-code/dandridge/title1/chapter1/section1-108) · [Signed code adoption ordinance](https://www.mtas.tennessee.edu/system/files/codes/dandridge-cao.pdf) · [Earlier code on the town website](https://www.dandridgetn.gov/wp-content/uploads/2015/03/dandridge-code.pdf)

Find the proposal on the board’s agenda and compare the text at each reading. If a committee returns an amendment or a substitute that addresses the same subject, the board may act on the new version the day it receives the report. The mayor signs the ordinances the board approves. Get the signed text and the minutes for the date it passed. [Board minutes and agendas](https://dandridgetn.gov/government/minutes/) · [Municipal code § 1-108](https://www.mtas.tennessee.edu/city-code/dandridge/title1/chapter1/section1-108) · [Dandridge charter](https://www.mtas.tennessee.edu/sites/default/files/private/charters/dandridge_cht.pdf#page=4)

For a change to an existing ordinance, compare the proposed text with the current code section. Ask the recorder for any amendments passed since that edition. [Municipal code](https://www.mtas.tennessee.edu/city-code/dandridge)
