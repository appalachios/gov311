## What this covers

Metro Nashville adopts national model codes, such as the International Residential Code, and adds its own local amendments. A requirement in Nashville can therefore differ from the model code.

This entry does not restate the codes or list the editions. It tells you where Metro publishes them.

## Where to read the codes

1. Open Metro's [adopted codes list](https://www.nashville.gov/departments/codes/codes-administration/adopted-codes-list) to see which edition of each code is in force.
2. Read the local amendments in the [Metro Code of Ordinances](https://library.municode.com/tn/metro_government_of_nashville_and_davidson_county/codes/code_of_ordinances).
3. Read the model code itself from its publisher. The International Code Council publishes the International Codes, and the National Fire Protection Association publishes the National Electrical Code.

The Code of Ordinances site turns away many automated tools. A person can open it in a web browser.

## Where to ask questions

Call the Codes Department at 615-862-6500. For inspection questions, call Building Inspections at 615-862-6550.
