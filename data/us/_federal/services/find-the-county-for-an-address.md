Open **Find Geographies** in the Census Geocoder. Enter the street address, city and state, select the current geography vintage for a present-day question and run the search. Check the matched address and read the county in the results. [Census Geocoder](https://geocoding.geo.census.gov/geocoder/geographies/onelineaddress)

The geocoder estimates a location along a street using address ranges. If the location is close to a boundary, check the parcel with the local assessor and confirm which government provides the service. In Tennessee, the county property guides identify the official map for each county.
